# General FAQ

Answers to common questions about this project and its documentation.

## How do I contribute to the docs?

Add or edit a markdown file under `docs/`, then regenerate `llms.txt`.

## Where do I report a documentation error?

Open an issue in the repository with the page name and the section heading.

## Which Python version is required?

Python 3.10 or newer, managed with `uv`.

## How do I preview the docs locally?

Run `uv run mkdocs serve` and open http://127.0.0.1:8000.
